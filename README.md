# 문검기 (문헌검색기) v0.6

검색어와 검색기간을 입력 → 검색 결과 확인 → AI 한글 번역 → 엑셀 저장.

## 실행
`run.bat` 더블클릭 → 브라우저에 문검기 화면이 열립니다. (처음 실행 시 필요한 프로그램을 자동 설치)

## AI 한글 번역 방법 (왼쪽 설정 → AI 선택)
기본값은 **🆓 Gemini 무료**입니다.

| 선택 | 비용 | 방식 |
|---|---|---|
| **🆓 무료 · Gemini API** (기본) | 무료 (Google 계정) | 자동. 무료 한도(분당 약 10회) 때문에 천천히 진행 |
| **🆓 무료 · 웹 채팅 복사·붙여넣기** | 무료 (ChatGPT·Gemini 웹, 회사/개인 Copilot) | 문검기가 만든 질문을 채팅에 붙여 넣고, 답변을 다시 붙여 넣음 |
| **💳 유료 · ChatGPT (OpenAI API)** | 사용량만큼 과금 | 자동, 빠름 |
| **💳 유료 · Claude (Anthropic API)** | 사용량만큼 과금 | 자동, 빠름 |
| **💳 유료 · Gemini (Google API)** | 사용량만큼 과금 (결제 설정한 키) | 자동, 빠름. Pro 모델 사용 가능 |

### 구글 Gemini API 키 받는 방법 (무료)
1. https://aistudio.google.com/api-keys 접속 → Google 계정으로 로그인
2. 처음이면 약관 동의 후 **API 키 만들기(Create API key)** 클릭
3. 만들어진 키 오른쪽의 **복사** 버튼으로 키 복사 (`AIza...`로 시작)
4. 문검기 왼쪽 설정 → AI 선택 **🆓 무료 · Gemini API** → **API 키** 칸에 붙여 넣고 **Enter** (✅ 표시 확인)
5. **연결 테스트**를 눌러 ‘연결 성공’ 확인

> 키는 이 PC의 `settings.json`에만 저장되며 깃허브에는 올라가지 않습니다. 키가 외부에 노출되면 같은 페이지에서 삭제 후 새로 만드세요.

### 유료 API 키 (이미 유료로 쓰는 분)
채팅 구독(ChatGPT Plus·Claude Pro·Gemini Advanced 등)과 **API 요금은 별개**입니다. 각 회사에서 API 결제를 설정한 키가 필요합니다.
- ChatGPT: https://platform.openai.com/api-keys (Billing에서 크레딧 충전)
- Claude: https://console.anthropic.com/settings/keys (Billing 설정)
- Gemini 유료: https://aistudio.google.com/api-keys 에서 결제(Billing)를 설정한 프로젝트의 키 — 무료 키에 결제를 붙였다면 같은 키 사용

### 번역 모델 선택
- API 키 입력 후 **🔄 사용 가능한 모델 불러오기** → 그 키로 쓸 수 있는 모델이 **번역 모델** 목록에 나옵니다.
- 목록에 없으면 **✏️ 직접 입력**으로 모델 이름을 적을 수 있습니다.
- Gemini는 **선택한 모델이 붐비면 다른 모델로 자동 전환** 옵션이 있습니다 (끄면 고른 모델만 사용).

### 참고
- Copilot은 무료 API가 없어 복사·붙여넣기로만 사용. 개인 Copilot은 입력 한도(약 4,000자)가 작아 1건씩 보내야 하므로 회사 계정 Copilot·ChatGPT·Gemini 권장.
- AI 작업: **초록 한글 번역(전체)** 기본, 필요 시 **초록 한글 요약** 선택.
- AI 결과는 자동 검사합니다 (빈칸, 초록이 있는데 '초록 확인 안됨', 일본어·한자 섞임, 너무 짧은 번역) → 해당 논문만 다시 요청.

## 사용 순서
1. 왼쪽 **설정**에서 AI 작업·AI·API 키·번역 모델·저장 폴더 입력 — 입력하면 자동 저장, **연결 테스트**로 확인
2. 사이트 탭(KoreaMed · RISS · 국회도서관)에서 검색어·시작연도·종료연도 입력 → **검색**
   - 동의어는 쉼표로 구분 (예: `thioctic acid, lipoic acid, alpha-lipoic acid`) → OR 검색
3. 결과 표 확인 후 **엑셀 만들기**
   - 파일명: `검색어명(시작-종료)_사이트_검색일자.xlsx` (예: `pioglitazone(2021-2026)_Koreamed_20261026.xlsx`)
   - 하위 폴더(예: `그리타존정(피오글리타존)`)를 적으면 그 폴더에 저장

### 사이트별 검색 조건
| 사이트 | 검색 조건 | 비고 |
|---|---|---|
| KoreaMed | `검색어[ALL] AND 시작:종료[DPY]` | 출판 월·학술지 약어 포함 |
| 국회도서관 | 고급검색 → 상세검색 → **연속간행물·학술기사 [전체]**, 검색분류 **[전체항목]**, 발행연도 범위 | **한글 + 영문 검색어** → 검색어별 엑셀. PC의 Edge(또는 Chrome)를 화면 없이 자동 조작 (100건에 2~3분) |
| RISS | 상세검색 → **국내학술논문**, 분류 **[전체]**, 발행연도 범위 | **한글 검색어 + 영문 검색어**를 함께 넣으면 한 번에 검색하고 엑셀은 검색어별로 따로 저장 (예: `피오글리타존(2021-2026)_RISS_…xlsx`, `pioglitazone(2021-2026)_RISS_…xlsx`). 0건이어도 검색 조건을 기록한 파일을 만듭니다. |

- RISS 목록에는 출판 월·쪽수·DOI가 없어 상세 페이지에서 저자·쪽수·DOI를 가져오고,
  DOI로 **PubMed → Crossref** 순서로 출판 월·학술지 약어를 보완합니다. 두 곳 모두 정보가 없는 국내 학술지는 출판 월이 빈칸입니다.
- RISS 목록의 초록은 2,000자에서 잘리므로, 잘린 경우 상세 페이지의 전체 초록을 씁니다.
- RISS 저자명: PubMed에 있으면 `Tseng CH` 형식, 없으면 RISS에 적힌 이름 그대로 (예: `전예린`, `Ofri Mosenzon`).

### 국회도서관 (자동 검색)
- 국회도서관은 검색 화면을 거치지 않은 직접 요청에는 결과를 주지 않아, PC에 설치된 **Microsoft Edge**(없으면 Chrome)를
  화면 없이 띄워 사람이 하는 순서(홈 → 검색 → 연속간행물·학술기사 → 발행연도 → 50건씩 넘김)대로 검색합니다.
  브라우저를 따로 설치할 필요는 없습니다.
- 초록은 국회도서관 결과 화면의 **‘초록’** 버튼과 같은 기능으로 가져오고, 없으면 PubMed에서 같은 논문을 찾아 보완합니다.
- 영문 논문은 PubMed에서 같은 논문을 찾아 저자 약어·학술지 약어·출판 월을 맞춥니다 (`Scherbak NN, et al. Diabetes Metab J. 2023 Sep;47(5):668-681.`).
- 엑셀 **비고** 칸: 자료 종류(국내기사/국외기사/학술지·잡지), 초록 출처, PubMed 번호, 외부기관 원문(KCI 등) 링크.
- 시험 결과(2021–2026): glimepiride 5건(초록 5건), 글리메피리드 0건, Thioctic acid 8건, 티옥트산·치옥트산 0건 — Codex 수작업 결과와 같음.

## 무료 Gemini 사용 한도
- 무료 키는 **모델마다 하루 약 20회** 요청 한도가 있습니다 (한 번에 논문 10건 → 모델당 하루 약 200건).
- 한 모델의 하루 한도를 다 쓰면 그 모델은 건너뛰고 다음 무료 모델(gemini-flash-latest → gemini-flash-lite-latest)로 자동 전환합니다.
- 모든 모델 한도를 다 쓰면 ‘오늘 무료 사용 한도를 다 썼습니다’가 나옵니다 → 다음 날(한국시간 오후 4~5시 초기화) 다시 하거나 유료 API 사용.

## 오류가 났을 때 — 로그 보기
- 왼쪽 설정 맨 아래 **🧾 로그 보기**를 누르면 최근 작업 기록 300줄이 보입니다.
  검색 시작·완료(건수·소요 시간), AI 번역 진행·모델 전환·재시도, 엑셀 저장, 오류(어느 단계에서 왜 났는지)가 남습니다.
- 로그 파일: `logs/munkeomgi.log` (2MB씩 최대 5개 보관). **로그 파일 내려받기**로 받아 전달하면 원인을 빨리 찾을 수 있습니다.
- API 키는 로그에 가려서 기록됩니다.

## 엑셀 구성
- **문헌정리**: 번호, 출판연도, 출판월, 논문명(원문), 논문명(한글), 서지정보
  (`Lee JH, et al. J Korean Med Assoc. 2026 Jun;69(6):492-501.`), 초록(한글 번역), 연구유형, DOI, ID, 출처 링크
- **원문 초록**: 저자 전체, 초록 원문, 키워드

## 구조 (사이트 추가 시)
- `core/models.py` 공통 논문 형식 · `core/excel.py` 엑셀 · `core/summarizer.py` AI 번역·요약
- `core/koreamed.py` KoreaMed 검색, `core/riss.py` RISS 검색, `core/nanet.py` 국회도서관 검색(브라우저 자동 조작),
  `core/enrich.py` DOI·제목으로 서지정보 보완(PubMed·Crossref), `core/log.py` 작업 기록
- 국회도서관·PubMed도 같은 형태(`search()`, `NAME`, `FILE_TAG`, 선택: `SECOND_QUERY_LABEL`)로 추가 후
  `app.py`의 `SOURCES`에 등록하면 탭이 활성화됩니다.
- `settings.json`(API 키 포함)은 이 PC에만 저장되며 깃허브에 올라가지 않습니다 (`.gitignore`).
